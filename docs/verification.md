검증일: 2026-09-11~12 KST. 자동 테스트, 실제 모델 호출, 브라우저 확인을 구분했습니다. 특정 합성 사례의 관찰 결과이며 전체 입력에 대한 성공률이 아닙니다.

## 자동 기능 검증

Python 3.12에서 `python -m pytest -q --junitxml=.tmp/test-results.xml` 실행: **18 passed in 13.27s**. A2A는 실제 HTTP, MCP는 독립 stdio 프로세스로 동작합니다. 모델은 fixture로 고정합니다.

| 범위 | 확인한 결과 |
|---|---|
| 정상·승인·중복 승인 | 오후 CT 선택, 승인 후 confirmed, 반복 승인에 같은 예약 반환 |
| 서류 누락·빈 후보 | needs_input에서 일정 조정 중단, 후보 없으면 no_slots |
| 취소·충돌·오래된 승인 | 후속 확정 차단, 충돌 표시, 버전 불일치 거부 |
| 세션·내부 API·입력 | 다른 세션 404, 내부 A2A 403, 입력 길이와 Origin 확인 |
| DB 원자성 | 같은 슬롯의 8개 경쟁 요청 중 1개만 성공 |
| 모델 근거 | 잘못된 ready·후보 밖 slot_id 주입 시 거부 |
| MCP 실패·지시 우회 | 성공으로 위장하지 않고 실패/추가 확인 상태 반환 |
| 응답 유실 복구 | DB 커밋 후 응답 유실을 주입, 같은 실행 재확인으로 중복 없이 복구 |
| 형식 오류 | 1회 재시도 후 복구, 반복 오류는 최대 2회 시도 후 실패 |
| A2A 보관 | 완료 Task 보관 수 제한 확인 |

Ruff와 Prettier의 코드·형식 검사도 통과했습니다. 별도의 침투 시험을 의미하지 않습니다.

## 실제 Gemini 검증

로컬 서버와 Vertex AI Gemini 2.5 Flash로 네 사례를 실행했습니다. `scripts/live_smoke.py`의 [실행 결과 요약](evidence/local-gemini-verification.json)을 제공합니다.

| 사례 | 기대 / 실제 상태 | 모델 호출 |
|---|---|---:|
| 오후 예약 | awaiting_approval / 일치 | 2 |
| 서류 누락 | needs_input / 일치 | 1 |
| 가용 시간 없음 | no_slots / 일치 | 2 |
| 누락 사례에 지시 우회 입력 | needs_input / 일치 | 1 |

네 사례에서 모델 형식 오류는 관찰되지 않았습니다. 형식 오류와 잘못된 업무 판단 방어는 자동 테스트의 의도적인 결과 주입으로 검증했습니다.

리비전 `examflow-00004-fph`에 `scripts/verify_deployment.py`를 실행했습니다. [실행 시각과 결과](evidence/deployment-verification.json)를 확인할 수 있습니다.

- 실제 gemini 모드 확인.
- EX-1001: A2A 응답 2개, CT-PM 선택, 승인 후 confirmed, 반복 승인 결과 동일.
- EX-1002: A2A 응답 1개, needs_input, 일정 조정 미실행.
- EX-1003: A2A 응답 2개, no_slots.

스킬의 `invoke.py`도 공개 서비스에서 실제 모델부터 합성 예약 확정까지 실행했습니다. 검증 범위가 겹치므로 테스트 수에 합산하지 않았습니다.

## 브라우저와 발표자료

브라우저에서 로컬 fixture와 공개 Gemini의 요청·진행·결과·승인 완료를 확인했습니다. 최종 배포의 390px 화면에서 제목과 입력 폼을 확인했습니다. 앞선 모바일 확인에서는 수평 넘침이 없었습니다. 실제 스마트폰 확인은 미수행입니다.

7장 PPTX의 파일 구조, 글꼴 정책, 편집 가능한 표 3개, 재가져오기 검증을 통과했습니다. 최종 PPTX를 다시 가져와 7페이지를 렌더링한 뒤 각각 시각 검토했습니다. 잘림이나 의도하지 않은 겹침은 관찰되지 않았습니다. 설치된 PowerPoint 앱 자체에서의 재생 검증은 미수행입니다.

## 미수행 범위

- Antigravity IDE 미설치로 IDE 내 스킬 자동 발견·직접 호출은 미수행입니다. 패키지와 HTTP 호출 스크립트의 로컬·공개 서비스 실행을 검증했습니다.
- 실제 병원 자료·의료적 판단·실제 예약 시스템·물리 기기 검증은 범위 밖입니다.
- 부하 시험, 장시간 안정성, 모든 프롬프트 공격, 다중 인스턴스 운영은 검증하지 않았습니다.
- 재시작 뒤 데이터 보존은 보장하지 않습니다. 비용 한도의 제한은 [배포 구성](deployment.md)에 기록했습니다.
